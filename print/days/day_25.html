Travel Rule 벤더 — 공개 사실 지도

메시징 프로토콜·Travel Rule 솔루션 시장을 **공개 자료로 확인되는 사실만** 정리합니다. 이 글을 읽고 나면 각 네트워크가 무엇이고 누가 운영하며 서로 어떻게 연동된다고 밝히는지, 그리고 무엇이 확인되지 않았는지를 구분할 수 있게 됩니다. 벤더 간 우열·추천·가격은 다루지 않습니다..

TL;DR

  • 모델은 셋: 양자 간 오픈 표준(TRP·TRISA) · 회원제 솔루션 네트워크(VerifyVASP·CODE·GTR·Sygna 등) · 멀티프로토콜 연동을 표시하는 솔루션(Sumsub·Notabene·CODE 등)
  • 2026-10-21 기준 정정: OpenVASP Association 은 TRP 표준을 관리하는 협회(이전 판의 "Ethereum·ENS·Whisper 기반"은 2020년 이전 설계), GTR 운영 주체는 Infozone Technologies(싱가포르)(이전 판의 "BitGo 등 컨소시엄"은 근거 없음), 데이터 모델 현행판은 IVMS 101.2023("IVMS101 v2" 없음)
  • 네트워크 규모(VASP 수)·가격·성공률·가입 소요기간은 공개 1차 근거가 없거나 자사 주장이라 이 문서에서 뺐습니다
  • 벤더 선택의 기준은 "누가 1위인가"가 아니라 우리 출금 상대방이 어느 네트워크에 있는가와 미연결 상대방 정책입니다

1. 시장 구조 — 3가지 모델

세 모델의 차이

  • 양자 간 오픈 표준 — 사양이 공개돼 있고 각 VASP 가 구현합니다. TRP 는 "Bilateral exchange of encrypted data (VASP-to-VASP). No data or metadata is ever exchanged with any third party" 라고 설명합니다(OpenVASP TRP).
  • 회원제 솔루션 네트워크 — 운영자가 회원을 검증하고 디렉터리를 제공합니다.
  • 멀티프로토콜 연동 — 한 솔루션이 여러 네트워크와의 연동을 표시합니다. 허브는 라우터이고, 실제 전송은 하부 프로토콜이 담당합니다.

2. 주요 벤더·프로토콜 — 공개 사실

아래는 2026-10-21 각 자사 페이지 열람 결과입니다(T3, 확신도 B). 네트워크 규모 수치는 자사 주장이라 인용하지 않습니다.

A. Notabene

  • 제품: SafeTransact·Notabene Flow·TAP. OpenVASP 회원. "Every Notabene customer has a live TRP 1.0 endpoint."
  • 2026-07-23 Ripple 의 전략투자(금액 비공개) 발표
  • 근거: Notabene About, Notabene TRP, Ripple 투자 발표

B. VerifyVASP

  • 홈페이지에 TravelRule API·VerifyName API·VerifyWallet 제품 표시
  • 운영 주체는 홈페이지에 명시되지 않음. 이전 판의 "람다256 + Chainalysis 합작" 지분 구조는 2026-10-21 공개 1차 근거로 확인되지 않았습니다
  • 근거: VerifyVASP

C. CODE (CodeVASP)

  • 운영: CODE Inc. 홈페이지 상호운용 목록에 CodeVASP·VerifyVASP·GTR·Sumsub·Sygna·Notabene·CryptoSwift 표시
  • 2026-03-25 비호스팅 지갑 식별 솔루션 게시
  • 이전 판의 "빗썸·코빗·코인원 3사 합작" 지분 구조는 홈페이지에서 확인되지 않음(2022 보도 기반으로만 전해짐)
  • 근거: CODE

D. Sumsub Travel Rule

  • 자체·GTR·CODE·TRP·Sygna 5개 프로토콜 연동 표시. 비호스팅 지갑은 자체 프로토콜과 블록체인 분석 파트너를 통한 "multiple verification methods"로 검증한다고 적음
  • 이전 판의 "본사 영국"은 이번 조사에서 확인하지 못해 삭제
  • 근거: Sumsub Protocols

E. Sygna (CoolBitX)

  • Sygna Bridge 2.0·IVMS101 지원 표시. Sumsub·GTR·CODE 가 지원 프로토콜로 올림
  • 이전 판의 "일본·동남아 거래소 다수"는 근거가 없어 삭제
  • 근거: Sygna

F. Global Travel Rule (GTR)

  • 운영: Infozone Technologies Pte. Ltd.(싱가포르). 홈페이지에 얼라이언스 회원 목록과 지원 프로토콜(Code·Sumsub·Sygna·Fireblocks), 제품(API·Manual·Wallet Verification·Out-Of-Network) 표시
  • 이전 판의 "BitGo 등 컨소시엄, 일부 미국·중남미"는 근거가 없어 삭제
  • 근거: GTR

G. TRISA

  • gRPC/protobuf 기반 오픈소스 프로토콜 + Global Directory Service. 오픈소스 노드 Envoy 가 TRISA 와 TRP 를 모두 지원한다고 밝힘
  • 2026-10-21 trisa.io 는 응답하지 않음 — 접속 불가만으로 운영 중단을 추정하지 말 것
  • 이전 판의 "일부 LATAM, 신흥시장 사용"은 근거가 없어 삭제
  • 근거: trisa.dev, GitHub trisacrypto/trisa

H. TRP (Travel Rule Protocol) · OpenVASP

  • OpenVASP Association(Zug)이 TRP 표준을 관리. 주간 TRP Working Group, GitLab 공개 사양(CC BY-SA 4.0), ISO 24165(DTI)·IVMS101 호환. TRP 벤더로 21 Analytics 등을 듦
  • 현행 TRP 버전 번호는 사이트에 표시되지 않음
  • 근거: OpenVASP, OpenVASP TRP, GitLab

I. 21 Analytics

  • 도메인을 21analytics.ch → 21analytics.co 로 이전(301). AOPP(주소 소유 증명 프로토콜) 용어집 운영
  • 근거: 21 Analytics AOPP

실무 포인트

위 사실은 모두 자사가 자기에 대해 밝힌 것입니다. 연동 목록은 "연동을 표시함"이지 품질·커버리지·안정성을 뜻하지 않습니다. 실제 도입 판단은 우리 출금 상대방 목록을 들고 각 네트워크에 직접 확인해야 합니다.

3. 벤더 선택 — 확인할 질문

이전 판의 "회사 유형별 추천" 표는 우열 평가여서 삭제했습니다. 대신 규범이 요구하는 것에서 출발한 질문 목록입니다.

질문 왜 필요한가 근거
우리 출금 상대방 상위 N 곳이 이 네트워크(또는 연동 네트워크)에 있는가 미연결이면 정보를 보낼 수 없음 FATF 2021 para 200–201 (sunrise 대응)
IVMS 101.2023 의 C1·LEI 제약(C9~C11)을 검증하는가 현행 데이터 모델 제약 IVMS 101.2023
관할별 금액 구간을 시점과 함께 설정할 수 있는가 영국 1,000 euros(~2026-06-29) → £800(2026-06-30~) S.I. 2026/621
한국 2027-02-19 전건화·요청 시 3영업일 추가정보를 지원하는가 금액 게이트 제거, 요청 응답 큐 시행령 §10-10 시행예정 판본
상대 VASP 실사 자료(인허가·트래블룰 이행)를 남길 수 있는가 한국 2027-02-19~ 고시 §28-2 등급 판정 감독규정 FIU 고시 제2026-2호
자기수탁 지갑 검증 방법은 무엇이고 어느 규범의 방법에 해당하는가 EU 는 1종 이상 열거, 한국 2027 은 동일인 요건만 EBA/GL/2024/11 ¶83
메시지·판단 기록을 내보낼 수 있는가 벤더 교체 시 기록 보존 —

4. 통합 vs 분리

Travel Rule + 거래모니터링 운영

KYC
  └─ Travel Rule 메시징
       └─ 거래모니터링 · 블록체인 분석
            └─ 내부 위험판단 엔진

FATF 7차 TU(2026-07-16)는 VASP 에 "transactions monitoring and blockchain analytics tools" 로 급속 이전을 탐지하라고 권고하지만, 이것은 트래블룰 메시징과 별개 통제입니다(7차 TU PDF). 이전 판의 "Chainalysis 는 VerifyVASP 합작을 통해 Travel Rule 제공", "TRM Travel Rule" 서술은 이번 조사에서 1차 확인되지 않아 뺐습니다.

실무 포인트

단일 벤더 통합은 편하지만 벤더 종속이 생깁니다. 어떤 구조든 메시지 원문·판단 근거·상대방 평가 기록을 자사 쪽에 보관해 두면 교체 비용이 줄어듭니다.

5. 한국 시장 운영 패턴

국내 VASP ↔ 국내 VASP
  ├─ ~2027-02-18: 100만원 이상만 정보제공 (in-force)
  └─ 2027-02-19~: 모든 이전 (enacted-not-in-force)
국내 VASP → 해외 VASP
  └─ 2027-02-19~: 저위험 허용 / 그 외 동일인 간만 / 고위험 제한 (고시 §28-2②)
국내 VASP → 자기수탁 주소
  └─ 2027-02-19~: 동일인 간만 허용, 위험 현저하면 제한 (고시 §28-2④)

2026 상반기 총 출고 62.8조원 중 트래블룰 적용은 9.5조원(약 15%)이었습니다(금융위 2026-10-01). 국내 사업자 간 메시지는 솔루션 네트워크를 통해 오가고, CODE 홈페이지는 VerifyVASP 를 상호운용 목록에 올리고 있습니다(B). 거래소별로 어느 네트워크를 쓰는지는 이 저장소가 1차 근거로 확인하지 않았습니다.

실무 포인트

2027-02-19 이후 해외 VASP 허용 여부는 메시지 연결뿐 아니라 상대 VASP 평가 결과로 갈립니다. 벤더가 연결을 제공해도 평가가 "그 외" 등급이면 동일인 이전만 허용됩니다.

6. POC 체크리스트

□ 우리 출금 상대방 목록 기준 연결 여부 실측
□ IVMS 101.2023 검증 (PayloadVersionCode 101/101.2023, C1, LEI)
□ 응답 시간 — 자사 실측 (공개 SLA 벤치마크 없음)
□ 미연결 상대방 정책 설정 (보류·수집 후 진행·거절)
□ 관할별 금액 구간의 유효기간 설정 (영국 2026-06-30 전환 등)
□ 한국 2027-02-19: 금액 게이트 해제, 요청 시 3영업일 응답
□ 상대 VASP 평가 자료 보관
□ 메시지 보존 — 관할별 기록보존 조문으로 기간 확인
□ 개인정보 암호화, 국외이전 근거
□ 기록 export 조항

7. 가격

이전 판의 가격 참고치(연 $20K~$1M+, 거래당 ~$0.10)는 출처가 없어 삭제했습니다. 가격은 공개되지 않으므로 견적으로만 확인할 수 있습니다.

8. 2026-10-21 기준 변화와 남은 미확인

표준

  • IVMS 101.2023 이 현행판(2023-08 발행, ISWG 2024-06-04 갱신 공표). "IVMS101 v2" 전망은 근거가 없습니다
  • DTI(ISO 24165)는 TRP 가 호환을 명시, LEI(ISO 17442)는 IVMS 101.2023 제약 C9~C11

FATF

  • R.16 개정(2025-06 총회)은 VASP 에 R.15 를 거쳐 간접 적용, 이행 기대시한 2030-12-31
  • R.16 이행 가이던스 초안 의견수렴 2026-06-24~2026-08-21, 2026-10-21 기준 최종본 미발간(proposed)
  • 이전 판의 "2026 후반 가이던스 → 모든 벤더 업데이트", "2030 발효"는 각각 낡거나 부정확한 표현이라 고쳤습니다

미확인으로 남은 것

  • 각 네트워크 회원 수·거래량 — 자사 주장만 있음
  • VerifyVASP·CODE 지분 구조, 상호 연동 완료 시점
  • 서명 표준(EIP-191/BIP-137) 사용 여부 등 자기수탁 검증 방식의 벤더별 세부

💼 실무 현장 (Industry Reality)

선택 흐름 — 우열이 아니라 상대방에서 출발

자주 나오는 오해

  • "Travel Rule 은 100만원 이상만" — 한국 ~2027-02-18 기준입니다. 2027-02-19 부터 전건이고, EU TFR 은 처음부터 금액 무관 전건입니다
  • "개인지갑 출금은 Travel Rule 과 무관" — 관할마다 다릅니다. EU 는 EUR 1,000 이상이면 자기수탁 주소 소유·통제 평가(TFR 제14조(5)·EBA GL ¶83), 영국은 reg 64G(정보 요청·미수령 시 지급 금지), 한국은 2027-02-19 부터 동일인 간만 허용(고시 §28-2④)
  • "외부지갑 등록제는 자율규제일 뿐" — 2026-10-21 기준으로는 맞지만 2027-02-19 부터 동일인 요건이 고시 의무가 됩니다
  • "GTR 은 BitGo 컨소시엄" — 운영 주체는 Infozone Technologies(싱가포르)입니다
  • "OpenVASP 는 Ethereum 기반 메시징" — OpenVASP Association 은 TRP 를 관리하는 협회입니다
  • "FIU 에 트래블룰 실패율을 분기 보고한다" — 그런 보고 의무의 근거 조문은 이 저장소가 확인하지 못했습니다

한국 특수 현실

  • 2027-02-19 전환: 정보제공 전건화, 추가정보 요청 시 3영업일, 해외 VASP 3등급, 자기수탁 동일인 요건, 1천만원 이상 자체 의심거래 감시체계가 같은 날 시작합니다(감독규정 §28-2 시행일은 기산점 문제로 미확정)

한국 시장 솔루션 지도

한국 가상자산사업자가 **법령상 연결해야 하는 인프라**와, 공개 자료로 확인되는 범위를 정리한 지도. 이 글을 읽고 나면 신규 VASP가 "어떤 제도에 어떤 시스템을 대응시켜야 하는가"를 그릴 수 있고, 업계 소문과 공개 사실을 구분할 수 있게 됩니다..

TL;DR

  • 한국 VASP의 시스템 요구는 세 법률에서 나온다: 특금법(AML·트래블룰·STR), 가상자산이용자보호법(§12 시장감시·기록 보존), 통신사기피해환급법(보이스피싱 임시조치, 거래소 적용 2026-10-01~).
  • 신고매뉴얼(2026-08-13 전면 개정)은 AML 업무 인력 4인 이상, 고유식별정보 처리 전산설비 국내 소재(클라우드 국내 리전 인정), 대주주·법령준수체계 변경 30일 전 사전신고를 정했다.
  • 트래블룰은 2026-10-21 현재 100만원 이상(in-force). 2027-02-19부터 다른 VASP로의 모든 이전으로 바뀐다(enacted-not-in-force).
  • 이전 판의 벤더별 거래소 매칭(KYC·KYT·트래블룰), 수탁사 목록, 법무법인·컨설팅 목록, 연봉표, 연간 투자 규모, 신고 수리율, DAXA 공동 가이드 목록은 공개 근거가 없어 삭제했다.

1. 한국 VASP가 연결되는 법정 인프라

제도 시스템 요구 근거
특금법 신고 AML 인력 4인 이상, 전산설비 국내 소재, 대주주 변경 사전신고 금융위 2026-08-13 신고매뉴얼
특금법 거래모니터링 업무규정 제76~81조 거래모니터링체계, 분석자료 5년 이상 보존 법제처 DRF 업무규정

이용자보호법 §12 이상거래 상시감시, 통보·신고. 상시감시·조치 결과 기록을 가상자산거래기록으로 보존(시행령 §13 6·7호) 가상자산이용자보호법; 시행령
통신사기피해환급법 상시 자체점검, 임시조치(지연·일시정지), 거래목적 확인, 지급정지, 환급 통신사기피해환급법

실무 포인트

"솔루션 지도"를 벤더 이름으로 그리면 금방 낡습니다. 제도 → 요구 기능 → 내부 담당으로 그리고, 벤더는 그 기능을 채우는 교체 가능한 부품으로 두는 편이 검사 대응에도 유리합니다.

2. 2025~2027 한국 일정 — 시스템 변경이 필요한 날짜

근거: 금융위 2024-07-08, 금융위 2025-10-29, 금융위 2026-04(출금지연, B), 금융위 2026-08-04, 금융위 2026-08-11, 금융위 2026-03-13. 감독규정 §28-2의 시행일은 기산점에 따라 2027-02-19 또는 02-21이 될 수 있어 확정되지 않았습니다.

3. KYC · 본인확인

한국 고객확인은 국내 본인확인 수단과 연동돼야 합니다. 글로벌 KYC 도구가 신분증 OCR·얼굴 매칭을 해도 국내 실명 확인을 대신하지는 못하므로 실무 구성은 "글로벌 도구 + 국내 본인확인" 조합이 됩니다.

이전 판의 "한국 거래소 대부분이 특정 KYC 벤더를 메인으로 사용" 같은 서술과 KYC 벤더 표는 공개 근거가 없어 삭제했습니다.

4. 거래모니터링 · 블록체인 분석

  • 법적 근거는 가상자산 전용 조문이 아니라 금융권 공통 「자금세탁방지 업무규정」 제76~81조다(본문에 "가상자산" 0회).
  • 2027-02-19부터 해외 VASP·자기수탁 지갑 대상 1천만원 이상 이전에 자체 의심거래 감시체계를 구축·운영해야 한다(시행령 §10-20 ⑦나, 고시 §28-2③). 자동 STR이 아니다.
  • FIU 자체는 2026년 업무계획에 "체이널리시스(가상자산 분석도구) 도입"과 심사분석 AI 도입을 넣었다(금융위 2026-02-05).
  • 개별 거래소의 분석 벤더·도입 연도는 공개 1차 출처로 확인되지 않는다. 이전 판의 "글로벌 4사 모두 한국 진입·한국 사무소" 서술은 근거가 없어 삭제했다.

자세한 흐름은 ../4-technology/kyc-kyt.md.

5. 시장감시 (가상자산이용자보호법 §12)

2024-08-22 금융위·금감원 현장점검 기록에서 확인되는 것(금융위·금감원 2024-08-22):

  • 점검 기준: 법률과 업계 자율규제인 「이상거래 상시감시 가이드라인」
  • 거래지원 부서와 분리된 전담 시장감시 조직
  • 가격상승률·거래량증가율·최고가 변동폭 등 임계값 초과 시 적출하는 자체 개발 분석시스템
  • 이용자 안내 → 거래유의 지정 → 주문·거래 제한 → 거래중단의 단계적 조치
  • 금융당국과 5대 원화거래소 간 핫라인

집행 실적: 금융위는 2026-07-20 법 시행 2년 성과로 조사 완료 40여 건, 고발·통보 30여 건, 과징금 2건을 공표했다(금융위 2026-07-20). 첫 과징금은 2025-09-03 테더마켓 자전거래 사건이다(금융위 2025-09-03).

이전 판의 시장감시 벤더명 서술은 공개 근거가 없어 삭제했습니다.

6. FDS · 보이스피싱 대응

  • 2026-10-01부터 거래소는 통신사기피해환급법상 "금융회사등"이다. 상시 자체점검으로 피해의심거래계좌등이 추정되면 이체·출금·가상자산 이전을 지연·일시정지(임시조치)하고, 즉시 통지·본인확인 후 해당 없으면 해제해야 한다.
  • 출금지연제도: 2025-05 도입, 2026-04-07 강화된 표준 내규 시행. 근거 집계는 2025-06~09 거래소 사기이용계좌 2,526개 중 1,490개(59%)가 예외계좌였고 피해금의 75.5%가 예외계좌에서 유출됐다는 것이다(B)(금융위 2026-04).
  • ASAP: 금융보안원 정보공유 플랫폼(2025-10-29 출범, 약 130개 금융회사, 9개 유형·90개 항목). 2026-08-04 금융보안원이 법정 정보공유분석기관으로 지정됐다. 가상자산거래소의 실제 참여 여부는 공개 자료로 확인되지 않는다(금융위 2025-10-29; 금융위 2026-08-04).

7. 트래블룰

  • 2026-10-21 현재 시행령 §10-10 제1호는 "1백만원 이상"(in-force, 2027-02-18까지).
  • 대통령령 제36592호(2026-08-18 공포)에 따라 2027-02-19부터 "다른 가상자산사업자에게 가상자산을 이전하는 모든 경우"로 바뀐다. 성명·주소는 이전과 동시에, 주민등록번호 등은 요청일부터 3영업일 이내 제공.
  • 해외 VASP는 저위험 허용 / 그 외 고객·상대방 동일인일 때만 허용 / FATF 고위험국·무인허가 제한의 세 등급.
  • 2026-10-01 금융위 실태조사: 2026년 상반기 총 출고 62.8조원 중 트래블룰 적용 9.5조원(약 15%)(금융위 2026-10-01).

솔루션별 네트워크 규모는 자사 주장이라 싣지 않습니다(보고서 부록 B #25). 솔루션의 공개 사실은 travel-rule-vendors.md.

8. 신고 요건 · 자율규제

  • 신고매뉴얼(2026-08-13): AML 업무 인력 4인 이상(겸직 인정 가능), 전산설비 국내 소재, 대주주·법령준수체계 변경 30일 전 사전신고, 주요주주 기준(의결권주식 10% 이상 등) (금융위 2026-08-13).
  • FIU는 2026-10-13 미신고 사업자 사이트 27건 접속차단을 공표했다(수사기관 통보 누적 44개)(금융위 2026-10-13).
  • 자율규제: 2024-08-22 점검 기록이 업계 자율규제 「이상거래 상시감시 가이드라인」을 점검 기준으로 명시했다. 출금지연제도도 금융위·DAXA·거래소가 함께 운영한다.
  • 기존 사업자 재신고 기한(보도상 2026-11-20)은 부칙 원문이 확인되지 않아 싣지 않는다(보고서 부록 B #9).

정보보호 인증 등 그 밖의 신고 요건은 ../2-regulations/korea-fiu-act.md를 보세요.

이전 판 §12(DAXA 설립 연도, 가입 조건, 2024~2026 공동 가이드 목록, "탈퇴 = 생존 불가", "준 라이선스")는 공개 근거가 없어 삭제했습니다.

9. 인접 분야 — 스테이블코인

  • FATF 7차 TU Annex A에서 한국은 스테이블코인 발행자 등록·인가 요구 "No"로 표시됐다(2026-02~06 자기보고)(7차 TU PDF).
  • 한국 2단계 입법(디지털자산기본법·원화 스테이블코인)은 진행 상황이 T4·C 수준이라 싣지 않는다(보고서 부록 B #10).
  • 7차 TU는 VASP가 발행자 동결·소각에 기댈 수 없을 수도 있다고 경고했다(para 35). 스테이블코인을 다루는 거래모니터링은 "동결 가능하니 안전" 가정을 두지 않아야 한다.

10. 한국 시장 진입 시 점검표

□ 특금법 신고 (신고매뉴얼 2026-08-13 기준 요건)
□ AML 업무 인력 4인 이상, 보고책임자 지정
□ 고유식별정보 처리 전산설비 국내 소재
□ 거래모니터링체계 (업무규정 제76~81조) + 분석자료 5년 이상 보존
□ 트래블룰: 현행 100만원 이상 → 2027-02-19 전건화 대비
□ 해외 VASP 3등급 분류·자기수탁 동일인 확인 절차 (2027-02-19~)

□ 거래소라면 통신사기피해환급법 임시조치·통지·해제·기록 절차 (2026-10-01~)
□ 출금지연제도 내규 (2026-04-07 강화 기준)

💼 실무 현장 (Industry Reality)

신규 VASP의 순서

법령 요건에서 역산하면 순서는 이렇습니다.

  1. 신고 요건 충족 설계: 인력(4인 이상)·전산설비 위치·대주주 구조
  2. 거래모니터링체계 문서화: 룰 목록, 임계값 근거, 검토 절차, 보존 정책 (업무규정 제76~81조)
  3. 트래블룰 연동: 2027-02-19 전건화와 해외 VASP 등급 분류까지 감안해 설계
  4. 거래소라면 시장감시(§12)와 FDS 임시조치(통신사기피해환급법)를 별도 출구로 설계

이전 판의 12개월 로드맵 기간, 단계별 투자 규모(연 ₩25~40억), 벤더 계약 비용, 인력 연봉표, "실제 수리율 약 30%", 신규 VASP 성공·실패 사례, 은행 제휴 현황, 규제기관 출신 인력 이동 서술은 출처가 없어 삭제했습니다.

자주 나오는 오해

  • "KYT 벤더만 붙이면 거래모니터링 의무 끝" — 업무규정은 절차·분석담당자·보고체제·보존까지 요구한다. 도구는 일부일 뿐이다.
  • "이상거래 감시 = AML" — 이용자보호법 §12의 이상거래는 불공정거래 우려 거래다. 보이스피싱·자금세탁은 다른 법의 다른 출구로 간다.
  • "2027년부터 1천만원 이상은 자동 STR" — 공포본은 "자체 의심거래 감시체계"다.
  • "트래블룰은 이미 전건 적용" — 2026-10-21 현재는 100만원 이상이다. 전건화는 2027-02-19.
