# 시각 설계 노트

법률 데이터베이스·금융 터미널·학술 레퍼런스의 조판을 참조한다.
전제: **판(카드)을 띄우지 않고 괘선과 여백으로 나눈다.**

---

## 1. 진단 — 무엇이 "AI가 만든 티"였나

| 증상 | 원인 | 처방 |
|---|---|---|
| 카드가 균질하게 나열 | 히어로·통계·계층·표가 전부 같은 `border+radius+shadow` | 카드 폐지. 그래프 뷰포트만 테두리 유지 |
| 위계가 평평 | 모든 섹션이 같은 굵기 `h2` | `§ 번호 + 표제 + 방주` 3단 섹션 머리 |
| 기계적 리듬 | 활자 22종·간격 40종이 임의값 | 활자 10단·간격 12단 스케일로 고정 |
| 한국어가 안 읽힘 | 줄길이 무제한, 행간 1.62, mono+넓은 자간 라벨 | measure 38em·행간 1.78·한글 라벨 전용 자간 |
| 색이 과함 | 링크·강조·계층이 모두 파랑 | 링크는 먹색, 계층색은 계층에만 |

## 2. 토큰

### 활자 스케일 — 본문 15px 기준, 상행비 ≈1.20 / 하행비 ≈1.12

| 토큰 | px | 용도 |
|---|---|---|
| `--fs-00` | 11 | 코드 배지 · 술어 · ID |
| `--fs-0` | 12 | 한글 라벨 · 메타 · 각주 |
| `--fs-1` | 13 | 부연 · 표 보조 · 인용 |
| `--fs-2` | 14 | UI 컨트롤 · 표 본문 · 목록 |
| `--fs-3` | 15 | **본문** |
| `--fs-4` | 17 | 도입문 · 항목 제목 |
| `--fs-5` | 20 | 섹션 표제 `h2` |
| `--fs-6` | 24 | 페이지 표제 `h1` |
| `--fs-7` | 32 | 홈 표제 (clamp 28→40) |
| `--fs-8` | 44 | 계보의 결론 수치 하나 |

### 행간 · 자간

| 토큰 | 값 | 적용 |
|---|---|---|
| `--lh-body` | 1.78 | 한국어 본문. 라틴 기준 1.6은 한글에서 답답하다 |
| `--lh-dense` | 1.60 | 표 셀 · 메타 |
| `--lh-head` | 1.45 | 소제목 |
| `--lh-tight` | 1.30 | 표제 |
| `--tr-display` | −0.028em | 표제. 한글은 조여야 덩어리로 읽힌다 |
| `--tr-head` | −0.016em | 제목 |
| `--tr-body` | −0.004em | 본문 |
| `--tr-ko` | +0.012em | **한글 라벨** |
| `--tr-label` | +0.085em | **라틴 코드 라벨만** (`§ 01` `PROV` `T1`) |

> 한글에 `+0.085em` + `uppercase` + mono 를 걸면 즉시 "기계가 짠 화면"이 된다.
> 라벨 서체를 둘로 나눈 것이 이번 개편의 핵심 중 하나다.

### 줄길이 — 한글 1자 ≈ 1em

| 토큰 | 값 | 실측 |
|---|---|---|
| `--measure` | 38em | 42~46자 (본문) |
| `--measure-lede` | 34em | 38~42자 (도입문) |
| `--measure-display` | 19em | 19~21자 (표제) |

### 간격 — 4px 배수

`--s-1…--s-24` = 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64 · 80 · 96.
이 12개 밖의 값은 쓰지 않는다.

### 곡률

`--r-1` 2px · `--r-2` 4px · `--r-3` 6px. 그 이상 없음. 전문 도구는 각지다.

## 3. 색

### 명도 축 (light / dark)

| 토큰 | light | dark | 대비 |
|---|---|---|---|
| `--paper` | `#fbfaf7` | `#111110` | 지면 |
| `--ink` | `#14140f` | `#f1f0ea` | 16:1 |
| `--ink-2` | `#4a4842` | `#b3b0a7` | 9:1 |
| `--ink-3` | `#6d6b63` | `#928f87` | 5.2:1 (AA) |
| `--rule` / `--rule-2` / `--rule-3` | 괘선 3단 | | |

라이트/다크는 `light-dark()` 하나로 선언한다. `[data-theme]` 은 `color-scheme` 만
뒤집으므로 **팔레트가 파일 안에 한 번만 존재**한다 (중복 선언 0줄).

### 계층 3색 — 고정. 변경 불가

| 계층 | light | dark |
|---|---|---|
| semantic | `#2a78d6` | `#3987e5` |
| dynamic | `#1baf7a` | `#199e70` |
| kinetic | `#eb6834` | `#d95926` |
| funnel | `#898781` (양쪽) | 계층이 아니라는 뜻 |

**계층색은 계층을 말할 때만 쓴다.** 이전에는 `--accent = --layer-semantic` 이라
링크·버튼·활성탭이 전부 semantic 파랑이었고, 그래서 "이게 L1 이라는 뜻인가?"가
흐려졌다. 지금 링크는 먹색 + 밑줄, 활성 탭은 먹색 2px, 주요 버튼은 먹색 배경이다.

### 신뢰 표식 — 색은 3차 부호

| 대상 | 1차 | 2차 | 3차 |
|---|---|---|---|
| 확신도 A~D | 문자 | 테두리 상자 | 색조 |
| 출처등급 T1~T5 | 문자 | **눈금 5칸 중 n칸** | 색 없음 |
| 그래프 노드 | 형태 | 세로 위치 | 계층색 |

출처등급은 서열이므로 색조 5개(기존: T1 보라 … T5 빨강 — 서열이 안 읽힌다)를 버리고
눈금 개수로 바꿨다. 흑백 인쇄에서도 등급이 그대로 읽힌다.

## 4. 조판 장치

| 장치 | 형태 | 이유 |
|---|---|---|
| 섹션 머리 | `§ 01` + 표제 + 우측 방주, 아래 1px 괘선 | 법령·보고서의 조판. 제목 반복을 위계로 바꾼다 |
| 판권장(census) | 타일 5장 → 괘선으로 나눈 한 줄, 수치 17px | 통계 타일은 대시보드의 전형. 수치는 작아도 신뢰를 준다 |
| 위임 사슬 | 세로 괘선 + 번호 원 + 우측 값 열 | 마지막 값만 44px — 페이지에서 가장 큰 것이 **결론 수치**다 |
| 시점 대조 | 두 열 대조, 미시행은 취소선 + 회색 | 차별 기능을 말이 아니라 화면으로 증명 |
| 지층 도해 | 카드 4장 → 색 눈금 3px + 괘선 단면 | 계층은 "쌓인 것"이므로 단면으로 그린다 |
| 노드 참조 | 테두리 칩 → `타입코드 + 제목`, 좌측 2px 계층 눈금 | 본문 흐름을 끊지 않는다 |
| 면책 | 경고 상자 → 하단 각주 | 매 화면 상단 상자는 아무도 읽지 않는다 |

## 6. 도상

이모지·아이콘 폰트·외부 라이브러리 없음. 전부 20×20 viewBox · stroke 1.5 · `currentColor`.
아이콘 수를 12개 → 8개로 줄였다 (네비게이션에서 전부 제거).

마크는 **위임의 하강**을 그린다: 세 막대가 아래로 갈수록 짧아지고(구체화),
끝점을 잇는 사선이 그 경로다. 방패·자물쇠 같은 관용 도상은 쓰지 않았다.
