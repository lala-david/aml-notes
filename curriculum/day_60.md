근거: [정본 보고서](../reports/가상자산%20AML%20KYT%20FDS%20트래블룰%20흐름.md) "2026-10-22 이후" 절. 모두 enacted-not-in-force 또는 예정이며, (B) 표시는 2차 출처 기반입니다. 한국 감독규정 §28-2의 정확한 시행일은 고시 기산점에 따라 2027-02-19와 이틀 어긋날 수 있어 확정되지 않았습니다.

트랙별로 이 일정을 이렇게 씁니다.

- **A 기술**: 2027-02-19 전건화 대비 — 100만원 미만 이전까지 IVMS 101.2023 메시지 처리량·자기수탁 동일인 확인 흐름 설계
- **B 법·규제**: FATF 2026-10 총회 결과·R.16 이행 가이던스 최종본 발간 여부(2026-10-21 기준 미발간) 추적
- **C 컴플 운영**: 1천만원 이상 해외 VASP·자기수탁 이전 "자체 의심거래 감시체계"(고시 §28-2③) 룰 초안 — 자동 STR이 아님
- **D 솔루션**: 해외 VASP 3등급(저위험 허용 / 동일인만 허용 / 제한) 판정에 필요한 상대 VASP 실사 데이터 정리

### 한국 AML 커리어 지도

4개 트랙은 업계의 기술·법무·컴플라이언스 운영·제품 직군에 대응합니다. 공개로 확인되는 인력 요건은 하나입니다: 2026-08-13 전면 개정된 신고매뉴얼은 VASP의 AML 업무 인력을 **4인 이상**으로 정했습니다([금융위 2026-08-13](https://www.fsc.go.kr/no010101/87521)).

이전 판의 직군별 "주요 채용사"와 연봉 범위, 해외 허브별 수요·소재 기업 서술, "가장 흔한 국제 이동 경로"는 공개 근거가 없어 삭제했습니다.

```
M1 (1~30일):

- 가상 거래소 ERA(연례 위험평가) 문서 작성
- 룰 카탈로그 10개 작성 — 각 룰에 Red Flag ID 또는 조문 근거
- 산출물 3축(임시조치 / 시장감시 통보 / STR) 분류 연습 케이스 10건

M3 (61~90일):
- 2027-02-19 시행 대비 체크리스트 (트래블룰 전건, 해외 VASP 3등급, 자기수탁 동일인, 1천만원 감시체계)
- 검사 Q&A 스크립트 — FIU / 금감원(§12) / 금융안전과(임시조치) 3분할
- 사내 교육 자료 1편
```

이전 판의 특정 벤더 자격 취득, "실제 STR 공개 사례 10건 분석"(STR은 비공개), "회사 ERA 문서 접근"은 실행 가능하지 않거나 근거가 없어 바꿨습니다.

### 자주 나오는 오해

- **"AMLO = 법무 출신"** — 이전 판의 "데이터·엔지니어링 배경 AMLO 증가, 특정 거래소 후보군" 서술은 근거가 없어 삭제했습니다. 다만 2026-10-21 기준 규범은 기술 역량을 요구합니다: FATF 7차 TU 권고 6-ii는 "transactions monitoring and blockchain analytics tools"를, 2021 가이던스 para 276은 자동화 + 사람 분석을, 업무규정 제79·80조는 분석 근거 기록을 요구합니다.
- **"자격증이 있어야 채용"** — 자격이 채용에 미치는 영향에 대한 공개 통계는 이 저장소에서 확인하지 못했습니다. 실무 산출물(룰 카탈로그·케이스 기록·설계서)로 역량을 보여 주는 것이 이 60일 커리큘럼의 방향입니다.
- **"60일로 충분"** — 60일은 **입문 완료**입니다. 규제는 계속 바뀝니다 — 2027년 1분기에만 한국·영국·태국·미국의 시행 일정이 겹칩니다.
